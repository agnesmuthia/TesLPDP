# Analisis Tes Bakat Skolastik (TBS) LPDP

Dokumen ini merangkum struktur tes dan tipe soal TBS LPDP. Sumbernya: file latihan *Drilling Soal TBS LPDP 2023* (±150 soal: Penalaran Verbal, Penalaran Numerik, Pemecahan Masalah, ditambah buku TPA berisi sinonim, antonim, analogi, kuantitatif, dan penalaran) serta informasi publik tentang pelaksanaan seleksi.

## 1. Format tes

| Subtes | Jumlah soal | Waktu | ± detik/soal |
|---|---:|---:|---:|
| Penalaran Verbal | 23 | 30 menit | 78 |
| Penalaran Kuantitatif | 25 | 30 menit | 72 |
| Pemecahan Masalah | 12 | 20 menit | 100 |
| **Total TBS** | **60** | **80 menit (±90 menit dengan jeda/instruksi)** | |
| Tes Kepribadian / SJT | 40 | 45 menit | 68 |

- Tes dikerjakan daring melalui aplikasi ujian (Exambrowser) dengan pengawasan Zoom.
- Waktu tiap subtes berjalan sendiri-sendiri. Subtes yang sudah selesai tidak bisa dibuka lagi.
- Passing grade yang beredar di media sosial (mis. 165 untuk reguler, 150 untuk afirmasi/parsial) **tidak resmi**. Rujukan yang berlaku tetap pengumuman di [lpdp.kemenkeu.go.id](https://lpdp.kemenkeu.go.id).
- Komposisi di atas diambil dari pelaksanaan periode sebelumnya. Cek panduan resmi untuk periode pendaftaran Anda.

## 2. Tipe soal (dari analisis PDF)

### Penalaran Verbal
| Tipe | Contoh pola dalam PDF | Kunci strategi |
|---|---|---|
| Analogi | `UNDANG-UNDANG : REVISI = RUMAH : ...`, `MERAH : ... = PUTIH : ...`, `PIRAMID : MESIR = ... : ...` | Ubah relasi menjadi kalimat ("X *digunakan oleh* Y"), lalu uji ke tiap opsi. Perhatikan urutan pasangan. |
| Silogisme / logika | Modus ponens/tollens, silogisme hipotetis, disjungtif, dilema, "Semua/Sebagian/Tidak ada", "belum tentu" | Tulis dalam simbol p → q. Waspadai konvers dan invers. |
| Penalaran analitik | Urutan nilai TOEFL/IELTS, umur, tagihan, posisi, KPK jadwal les | Gambar garis urutan atau tabel posisi di kertas coretan. |
| Sinonim/Antonim (TPA) | `CERUK = LEKUK`, `KONVENSI = KESEPAKATAN` | Hafalkan kosakata serapan dan istilah akademik. |

### Penalaran Kuantitatif (Numerik)
| Tipe | Contoh pola |
|---|---|
| Deret angka | `3, 6, 4, 8, 6, ...`, deret berselang 2–3 pola, `10, 21, 43, 87`, kuadrat, Fibonacci |
| Deret huruf | `C, W, F, V, I, U, ...`, `A Z B Y D W G ...`, pola maju–mundur |
| Aritmetika/aljabar | Persen, pecahan, eksponen, `x² + y²` dari `x + y` & `xy`, SPLDV, operasi `p*q = q² − p` |
| Perbandingan x & y | `x = 5%`, `y = 1/5` dengan opsi x > y / x < y / x = y / tidak dapat ditentukan |
| Soal cerita | Umur, tabungan, uang sisa/kurang, sewa tenda bertingkat, ternak, kecepatan, kerja bersama |
| Geometri & statistika | Luas lingkaran (skala jari-jari), median dari frekuensi, rata-rata |

### Pemecahan Masalah
| Tipe | Contoh pola |
|---|---|
| Tabel data | Produksi karet per provinsi, mencari rata-rata/kontribusi/pertumbuhan |
| Grafik batang/garis | Lowongan CPNS per kementerian |
| Diagram lingkaran | Komposisi buah dan relasi antarkategori |
| Wacana | Teks kopi Indonesia, berisi ide pokok, pernyataan TIDAK benar, dan inferensi |
| Masalah kontekstual | PIN ponsel, tarif, jadwal |

## 4. Catatan keaslian soal
Soal ujian LPDP bersifat rahasia, jadi tidak ada pihak yang bisa menjamin soal latihannya "persis sama" dengan soal ujian. Bank soal di aplikasi ini adalah soal orisinal. Format, pola, gaya bahasa, dan tingkat kesulitannya disusun mengikuti PDF latihan TBS 2023. Soal numerik, logika, dan analitik dibuat oleh generator. Kunci jawabannya dihitung oleh program, dan teka-teki analitik/PIN diverifikasi secara *brute force* agar jawabannya tunggal. Angka pada tabel, grafik, dan wacana bersifat ilustratif.
